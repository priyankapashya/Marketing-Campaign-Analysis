# 📊 Marketing Campaign Analysis Dashboard

## Project Objective

The objective of this project is to analyze marketing campaign performance across different regions and campaign types.

The dashboard helps identify high-performing campaigns, compare revenue and marketing spend, evaluate ROI, and understand regional performance.

It provides interactive insights that can help businesses make better data-driven marketing decisions.

## Project Structure

The project is organized into the following folders and files:

- `data/` – Contains the CSV datasets used for the analysis.
- `images/` – Contains screenshots of important dashboard visuals.
- `notebooks/` – Reserved for Jupyter notebooks used for analysis.
- `src/` – Contains the Python source code used in the project.
- `README.md` – Provides project documentation, methodology, insights, and instructions.

## How to Run

1. Clone this repository to your local computer.
2. Open the project folder in Visual Studio Code.
3. Open the Power BI dashboard file.
4. If required, refresh the data to load the latest information.
5. Use the available slicers and filters to explore campaign performance, revenue, spend, ROI, and regional insights.
